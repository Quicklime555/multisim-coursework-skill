# Multisim Coursework Skill

一个面向电子仿真实验课程的 Agent Skill，用来减少重复查器件、反复调整无效截图和手工整理实验报告的工作。

它不会替你在 Multisim 中自动摆放或连线，也不会伪造实验数据。你完成电路和仿真，它负责把材料整理成稳定、可核对的工作流。

## 能做什么

- 从作业要求、PPT、PDF或参考电路图整理 Multisim 元器件型号与关键参数；
- 在搭建前告诉你完成后需要提交哪些截图；
- 检查示波器、函数发生器和常用仪表窗口是否足以支持实验结论；
- 发现明显的元件单位、时基、量程、触发和通道重叠问题；
- 根据真实截图撰写实验原理、实际设置和结果分析；
- 在环境支持时续写样例 DOCX，保持图号和排版连续。

## 安装

### 让 Agent 安装

把下面这句话交给支持安装 Skill 的 Agent：

```text
请帮我安装这个 Skill：https://github.com/Quicklime555/multisim-coursework-skill
```

### 命令安装

```bash
npx skills add Quicklime555/multisim-coursework-skill
```

如果宿主不支持上述安装方式，也可以下载仓库，把包含 `SKILL.md` 的目录复制到宿主的 Skills 目录。

## 配置与依赖

无需账号、密钥或额外配置。核心流程依赖宿主能够读取用户提供的图片和文档。

- Multisim 电路搭建与运行通常在 Windows 完成。
- 读取 PPT/PDF、编辑 DOCX 和渲染检查取决于宿主提供的文件能力。
- 缺少 DOCX 编辑能力时，Skill 会退化为交付可直接粘贴的文案和插图顺序。
- 命令安装方式需要 Node.js，但 Node.js 不是 Skill 本身的运行依赖。

当前版本在 Windows 环境完成过真实工作流验证；macOS 和 Linux 仅适用于材料整理与报告文案，未验证 Multisim 运行和 Word 视觉渲染。

## 数据与隐私

仓库不包含任何课程课件、作业、实验电路、截图或个人信息。Skill 只要求读取你主动提供的材料；材料如何被处理取决于你所使用的 Agent 宿主及其隐私政策。

公开提交示例或问题前，请移除姓名、学号、班级、教师材料、绝对路径和无关桌面信息。

## 使用边界

- 适用于 Multisim 课程实验准备、截图检查和报告整理。
- 不用于普通电路理论问答或与课程无关的通用写作。
- 默认只检查会使实验结论失效的明显问题；要求逐线排错时请明确说明。
- 这是非官方社区项目，与 NI 或 Multisim 没有隶属或背书关系。
- 用户应遵守所在课程的学术诚信和材料版权要求。

## 验证

仓库包含匿名评估用例，覆盖器件清单、截图要求、空白波形、通道重叠、元件单位、DAC计算、Word续写和缺少运行证据等情况。

发布前使用兼容的 Skill 校验器检查 `SKILL.md`、引用路径、评估数据和脱敏风险。
